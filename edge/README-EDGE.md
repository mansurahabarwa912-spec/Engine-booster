# Microsoft Edge - NOT Internet Explorer - READ THIS
## Edge vs IE - Critical
- Microsoft Edge = Chromium (Blink + V8). Same engine as Google Chrome. SUPPORTED.
- Internet Explorer 11 = Trident engine. Retired by Microsoft on June 15, 2022. NOT SUPPORTED. DO NOT USE.
- If you open this app and it says "Internet Explorer" in the top bar, you are in the WRONG browser. Close IE, open Edge.
## How to use Engine Booster in Edge
1. Open Microsoft Edge (blue/green wave icon, NOT blue 'e' with gold ring - that is IE)
2. Go to your Render URL / demo link
3. Check top badge says "Optimized for Microsoft Edge"
4. Install as App: Edge > ... (top right) > Apps > Install this site as an app
5. Pin to taskbar: Edge > ... > More tools > Pin to taskbar
6. Open directly via protocol: microsoft-edge:https://enginebooster.app
## How to set Edge as default (Windows)
Settings > Apps > Default apps > Web browser > Microsoft Edge
## Developer check
- Open Edge > edge://version - should say Chromium version, NOT Trident/MSIE
- Open DevTools F12 > Console - if you see 'MSIE' or 'Trident', you are in IE mode. Turn off IE Mode: edge://settings/defaultBrowser > Allow sites to be reloaded in IE Mode = OFF
